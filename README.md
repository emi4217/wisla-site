# Wisła

Статические страницы политики конфиденциальности приложения Wisła.

- `index.html` — украинская версия.
- `ru/index.html` — русская версия.
- `style.css` — локальные стили.

GitHub Pages публикует корень ветки `gh-pages`.
Страницы работают без JavaScript, внешних шрифтов и аналитики.
Исходники iOS-приложения в этот репозиторий не входят.
